# Локальный сервер Rust для скринов скинов

Сервер с Oxide и плагином `SkinShot`: опубликованные в Workshop скины (даже ещё не принятые Facepunch) видны в игре, если у предмета стоит их Workshop ID.

## Запуск

```powershell
.\tools\rust-server\rust-server.ps1          # первый раз ставит всё сам (~10 ГБ в C:\rustserver)
.\tools\rust-server\rust-server.ps1 -Update  # после патча Rust: обновить сервер и Oxide
```

Первый старт генерирует карту несколько минут; готов, когда в логе `Server startup complete`. Лог — `C:\rustserver\server.log`.

В клиенте Rust: **F1** → `client.connect 127.0.0.1:28015`.

Команды пишутся **в чат** (Enter, со слэшем) или **в консоль F1** без слэша: `sauna [n]`, `build`, `skin <id>`, `bp`, `giveskin <shortname> [skinId] [кол-во]`.

## Команды в чате (только админ — владелец ставится автоматически по Steam-аккаунту этого ПК)

| Команда | Что делает |
|---|---|
| `/sauna [n]` | выдаёт все опубликованные предметы Sauna со скинами (11 шт.); `n` — сколько штук каждой мебели, одежда по одной |
| `/build` | набор для стройки: план, киянка, шкаф, 100k дерева и камня, 50k фрагментов, 2000 МВК |
| `/give <shortname> [skinId] [кол-во]` | любой предмет со скином, напр. `/give locker 3840340102` |
| `/skin <id>` | перекрасить предмет в руке, а если руки пусты — объект перед собой |
| `/skin <id> look` | перекрасить только объект перед собой |
| `/t <час>` | время суток: `/t 12`, `/t 21` |
| `/bp` | изучить все чертежи (админу это делается и автоматически при входе) |

Полезное в F1: `noclip`, `god true`, `debugcamera` (свободная камера), `graphics.fov 70`, `env.time 18`, `inventory.give wood 10000`. Скриншот — F12 (Steam), `ingame_import.py` подхватывает их как обычно.

Список ID — в `SkinShot.cs` (`Sauna`). Новый предмет после публикации — дописать туда строку.

**Меню крафта показывает только скины из Steam-инвентаря** (купленные/принятые), наших там не будет. Поэтому скин ставится на сам предмет: `/sauna`, `/give`, `/skin`. А если скрафтить предмет из списка Sauna без скина, плагин сам поставит на него скин Sauna.
