## Концепции

### 1. «Ламповый» — радиолюбитель-выживший ⭐ рекомендую

**Идея.** Выживший собрал электрику из довоенного хлама: радиолампы, медная
обмотка, бакелит, лакированное дерево, латунные ручки. Всё тёплое, оранжевое,
ламповое. Rust прямо поощряет такую историю: в игре есть электросистема, и
игроки вечно что-то паяют.

- **Электропечь** → ламповый усилитель: ряд радиоламп, светящихся нитью
  накала (это и есть свечение, естественное, без неона), деревянный корпус,
  латунная решётка, паутина проводов.
- **Одежда:**
  - Miner Hat — вместо фонаря лампа-триод (шанс 1 из 14, продажи ~31 тыс.);
  - Tactical Gloves — перчатки радиомонтажника с намотанной проволокой и
    прожжёнными паяльником пятнами (1 из 15);
  - Vagabond Jacket / Snow Jacket — куртка с нашитыми экранными сетками,
    катушками, бакелитовыми пуговицами.
- **Расширение сета:** Locker (радиошкаф — №1 в нашем рейтинге), Large Box,
  Chair, Auto Turret (антенна, лампы), Custom SMG.
- **Палитра:** тёмный орех, бакелит-коричневый, латунь, тусклая медь +
  оранжево-янтарное свечение нитей.
- **Почему зайдёт игрокам:** узнаваемая «тёплая» эстетика, красиво светится
  ночью, но не кислотно; подходит под электрику Rust.
- **Риски:** легко скатиться в чистый стимпанк (Gear Mechanism уже есть) —
  держаться именно радиоэлектроники, без шестерёнок.

### 2. «Баня» — сауна посреди апокалипсиса ⭐ самая смешная и уникальная

**Идея.** В Rust все рождаются голыми — так пусть хоть париться с комфортом.
Ноль работ в Workshop по теме — абсолютно свободная ниша, при этом её мгновенно
понимает игрок из любой страны (баня/сауна есть в Финляндии, России,
Скандинавии, Японии, Турции — текст не нужен).

- **Электропечь** → электрокаменка: решётка с горой камней, раскалённых
  снизу (свечение — между камнями), деревянное ограждение из реек, ковшик,
  пар.
- **Одежда:**
  - Burlap Headwrap — полотенце, накрученное тюрбаном / войлочная банная
    шапка (1 из 10, продажи ~21 тыс.);
  - Hide Poncho — махровый халат / простыня (1 из 10);
  - Snow Jacket — овчинный тулуп, чтобы выбежать в снег (1 из 9,
    зимний сезон!);
  - Burlap Trousers / Shirt — льняное бельё.
- **Расширение сета:** Bed (полок), Chair (лавка), Wood Storage Box
  (кадушка), Sleeping Bag, Locker (раздевалка), Rock (камень из каменки),
  оружие — с ручками из берёзы и веником.
- **Палитра:** светлая липа/осина, потемневшее от пара дерево, серый
  базальт, войлок, лён + красно-оранжевое свечение камней.
- **Почему зайдёт:** юмор, уют, мем «голый ньюби в бане» сам просится; сет
  выглядит дружелюбно и не похож ни на что в магазине.
- **Риски:** соответствие тиру — деревянная «броня» не должна выглядеть
  крепче, чем она есть; не делать обнажённую натуру и откровенный юмор.

### 3. «Самогонщик» — аппарат на болоте

**Идея.** Деревенский самогонщик-отшельник: медный перегонный куб, змеевик,
бочки, бутыли, заплатки, болотная грязь.

- **Электропечь** → перегонный аппарат: медный куб сверху, змеевик,
  манометр, подтёки; свечение — раскалённый ТЭН под кубом.
- **Одежда:** Hide Poncho, Burlap Headwrap, Boonie Hat, Burlap Shirt/Trousers
  (комбинезон, кожаный фартук).
- **Расширение сета:** **Double Barrel Shotgun** (классика жанра и №3 в
  рейтинге!), Locker (шкаф с бутылями), Wood Storage Box (бочка), Chair.
- **Палитра:** окисленная медь (зелёная патина), рыжая ржавчина, болотный
  зелёный, мешковина.
- **Риски:** тема алкоголя — без надписей «XXX» и этикеток; медь как
  материал уже есть (Copper), отличаться нужно сюжетом и формой, а не
  материалом.

### 4. «Стеклодув» — мастерская из мусора

**Идея.** Выживший переплавляет бутылки из мусорок в стекло: раскалённое
стекло, бирюзово-янтарные потёки, кожаные фартуки.

- **Электропечь** → стеклоплавильная печь: окно с жидким стеклом (свечение),
  наплывы стекла снаружи.
- **Одежда:** кожаный фартук (Hide Vest), Tactical Gloves с термозащитой,
  Burlap Headwrap; вставки из бутылочного стекла.
- **Расширение:** Locker / Large Box с витражами, Water Purifier, оружие с
  стеклянными вставками.
- **Риски:** соседство с Molten / Forge (лава) — держать холодные бирюзовые
  и зелёные цвета стекла, а не огненные.

## Кратко: по два примера и понятность для англоязычных игроков

| Концепция | Название для Workshop | Пример 1 | Пример 2 | Понятно англоязычным? |
|---|---|---|---|---|
| Ламповый | **Tube Amp** / Vacuum Tube | Электропечь → ламповый усилитель с рядом светящихся ламп | Miner Hat → радиолампа вместо фонаря | Да, «tube amp» знает каждый гитарист. Не писать «Valve»: в Rust это читается как вентиль |
| Баня | **Sauna** | Электропечь → каменка с раскалёнными камнями | Burlap Headwrap → полотенце-тюрбан; Snow Jacket → тулуп «выскочить в снег» | Да, но только как «Sauna»; «Banya» мало кто знает. Визуал (рейки, камни, полотенце, ковшик) узнаётся без слов |
| Самогонщик | **Moonshiner** | Электропечь → медный перегонный куб со змеевиком | Double Barrel Shotgun → обрез самогонщика, обмотанный бечёвкой | Даже лучше, чем русскоязычным: классический американский образ (Аппалачи) |
| Стеклодув | **Glassworks** | Электропечь → печь с окном, за которым жидкое стекло | Tactical Gloves → термоперчатки со вплавленными осколками бутылок | Слово понятно, но визуал слабее: издалека «просто блестит», горячее стекло легко спутать с лавой (Molten, Hell) |

## Стимпанк — почему нет

- Для электропечи место **уже занято**: в 2026 приняли сет **Gear Mechanism**
  (шестерёнки), в нём есть Electric Furnace, Garage Door, Metal Door, Shop Front.
- В Workshop тесно: `steampunk` — 132 работы, `gears` — 322.
- Принятые раньше: Steampunk AR (2024), Steampunk SMG (2021), Steampunk
  Leather Mask, Victorian Furnace, Brass Vending Machine, Brass Sentinel Door.
- Классический стимпанк — чистая викторианская латунь, а Facepunch хочет
  грязное и самодельное.
- Использовать можно элементы (латунь, манометры, заклёпки) внутри
  «Лампового» как дизельпанк, но **без шестерёнок**.

**Вывод.** Две сильнейшие темы — **«Баня»** (уникальная, простая в

(самая «игровая» и красивая, сочетается с Locker и электрикой Rust).
Для англоязычной аудитории сильнейший — **Moonshiner** (+ Double Barrel из топ-5).
