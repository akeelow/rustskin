| Карта | наша | оригинал |
|---|---|---|
| diffuse | 1024, RGBA | 1024, RGBA |
| normal | 1024, RGBA | 1024, RGBA |

Синий канал Normal: min 255 (B = 255, как у оригинала).

## 2. Шов развёртки сзади (остров 1, столбцы 0 и 1023)

Строк на шве: 518. Разница цвета через шов: средняя 27.1, 95 % 42.0 (для сравнения — между соседними столбцами внутри острова: 8.1). Разница нормали: средняя 55.3.

## 3. Отступы

- diffuse: в полосе 1–8 px вокруг островов залито 100.0 %
- normal: в полосе 1–8 px вокруг островов залито 91.8 %
- specgloss: в полосе 1–8 px вокруг островов залито 87.4 %
- occlusion: в полосе 1–8 px вокруг островов залито 99.6 %

## 4. Нормаль стенки

Средняя по стенке: R 127.8, G 139.4 (ровно — 128/128; сдвиг > 6 — наклон всей поверхности).
Полосы по граням low-poly ищутся по профилю среднего R вдоль u (32 грани по кругу — период 32 px):
гармоника 32 (грани): 76, соседние 30–34 без неё: 390; гармоника 18 (клёпки): 752.

## 5. Асимметричные детали

Лист: стенка (остров 1, уникальный), θ = 52.0°, y = 0.302. Узлы верёвки — на ушках (общие 5/9) — одинаковые на обоих ушках по замыслу (обрезанная ручка), строятся у +x и отражаются.
Нахлёст обруча: θ = -68.0° (остров 1). Гнездо дроби: θ = -44.0° (остров 1).
