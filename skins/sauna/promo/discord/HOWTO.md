## Шаги

1. **Войти.** Открыть ссылку сервера → **Join** → принять приглашение в своём Discord. Если сервер просит
   нажать реакцию или кнопку под правилами, чтобы открылись каналы, — нажать.
2. **Прочитать правила** (канал вроде `#rules` / `#welcome` / `#info`). Проверить пять вещей:
   - как называется канал для показа работ (`#showcase`, `#skin-showcase`, `#workshop`, `#share-your-skins`…);
     это чат или форум (форум = у каждого поста своя ветка с заголовком);
   - можно ли там ссылку на Workshop / коллекцию, или ссылки только в отдельном канале (`#workshop-links`, `#self-promo`);
   - как часто можно постить свою работу (раз в неделю? одна ветка на сет?);
   - нужна ли роль или уровень, чтобы писать в этот канал;
   - есть ли отдельный канал для разбора работ (`#feedback`, `#critique`) — если есть, пост с вопросами лучше туда.
   Если ссылки запрещены — убрать из текста последнюю строку. Если что-то непонятно — скриншот правил мне.
3. **Открыть канал показа** и полминуты полистать: как пишут другие (длина, картинки, ссылки).
4. **Пост 1.** Перетащить три картинки из этой папки по порядку: `1_collage_ingame.jpg`, `2_stove_night.jpg`,
   `3_door_day.jpg`. Текст — блок «Пост 1» ниже. Если это форум, заголовок ветки: `Sauna - my first set (11 skins)`.
   Ссылка в `< >` — так Discord не добавит большое превью, а три картинки останутся главными.
5. **Не писать** «vote» / «upvote» / «thumbs up», не отвечать на «vote for vote» — просим только отзыв.
6. **Отвечать на отзывы** в течение дня, коротко: благодарить, на замечание — уточнить, что именно не так
   (готовые ответы ниже). Дельные идеи прислать мне — запишу в `CRITIQUE_ART.md`.
7. **Пост 2 (30.11–01.12)**, картинка `robe_wave_day.jpg`. Если показ — форум, написать ответом в своей же ветке;
   если чат — отдельным сообщением, если правила разрешают пост раз в неделю. Текст — «Пост 2».
8. **Ссылку на пост** (правый клик → Copy Message Link) прислать мне — посмотрю, был ли прирост на страницах.

## Готовые ответы

- Похвала:
  ```
  Thanks, appreciate it!
  ```
  > Спасибо, приятно!
- Замечание по детали:
  ```
  Good point, thanks. Is it the colour or the shape that throws it off for you?
  ```
  > Хорошее замечание, спасибо. Тебя смущает цвет или форма?
- «Too bright / not Rust enough»:
  ```
  Fair. Only the firebox, the embers in the box, the locker niches and the door window glow - the rest is plain worn wood and metal. Which piece looks off to you?
  ```
  > Справедливо. Светятся только топка, угли в ящике, ниши шкафчика и окно двери — остальное просто старое
  > дерево и металл. Какой предмет выглядит не так?
- «Is the door window see-through?»:
  ```
  No, the glass is opaque - the palm print and the glow are painted on, you can't see through it.
  ```
  > Нет, стекло непрозрачное — отпечаток и свечение нарисованы, сквозь него ничего не видно.
