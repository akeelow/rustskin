# Видео каменки: день → ночь — как снять

Одна запись ~40 с, на всё ~15 минут. Монтаж (16:9 и 9:16) и тексты делает агент: [make_video.py](make_video.py),
[TEXTS.md](TEXTS.md).

1. **Включи запись.** Проверь, что Xbox Game Bar включён: Параметры Windows → Игры → Xbox Game Bar. Запись потом начинается и останавливается **Win+Alt+R**, файл ложится в `C:\Users\akeel\Videos\Captures`.
   Запасной вариант — запись игр Steam (Steam → Настройки → Запись игр → «Запись по запросу», старт/стоп Ctrl+F11,
   потом оверлей Shift+Tab → Записи → Экспорт в MP4).
2. **Открой каменку.** Rust → **Workshop** → выбери свою опубликованную **Sauna Stove** (v3.1, страница 3840311723) →
   **EDIT**. Если редактор открылся пустым — загрузи карты v3.1 из `skins/sauna/electric-furnace/export/`:
   Diffuse `ElectricFurnace_v3.1_diffuse_cutout.png` + **Alpha Cutoff 1.00**, Normal, Metal/Gloss, Occlusion,
   Emission `..._v3.1_emission.png` + **Emission Color 255**. Остальные ползунки не трогай.
3. **Сверни панель** зелёной стрелкой справа вверху (режим предпросмотра, как для F12-кадров). Внизу справа останутся
   ползунки SKYBOX и TIME.
4. **Поставь TIME на полдень** (середина ползунка, как на кадрах 22.11).
5. **Камера:** каменка **анфас, чуть сверху** (видно решётку топки и край плиты). Зажатая кнопка мыши + WASD —
   двигаться, обе кнопки — зум. Размер: каменка по высоте **чуть больше половины экрана** — верх ниже надписи
   «SAUNA STOVE», низ выше нижних кнопок. По ширине — центр каменки **чуть левее центра экрана**. После этого
   камеру не трогай.
6. **Запиши:** Win+Alt+R → 5 с стоишь на полудне → **плавно, 20–25 с**, тяни TIME **вправо до упора** (если справа
   не ночь, а рассвет — повтори запись, потянув влево) → 5 с держишь ночь → Win+Alt+R. Мышь потом уведи с
   ползунка: всё вне каменки агент обрежет.
7. **По желанию, второй файл:** ночь, медленный облёт каменки на пол-оборота (~15 с).
8. **Положи файл(ы)** из `C:\Users\akeel\Videos\Captures` в **`skins/sauna/promo/video/raw/`** и напиши агенту
   «запись в raw». Имя файла любое.

Почему так: огонь в топке — лучший «крючок» сета; ночью в редакторе светится только топка
([PROMO.md](../../PROMO.md), разделы 3 №6 и 4.3 п. 1). Рамка в шаге 5 нужна, чтобы из одной записи вырезать и
горизонтальное видео (без заголовка редактора), и вертикальное для Shorts.
