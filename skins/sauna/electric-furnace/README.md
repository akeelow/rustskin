# Sauna Stove (Electric Furnace)

> Статус: 🟡 бриф готов, следующий шаг: скачать оригинальные текстуры.
> Сет: [Sauna](../README.md).

## Образ

Электропечь, которую выживший превратил в каменку: обшил железный корпус
рейками, в топке вместо поддонов гора камней, раскалённых снизу. Через
смотровое окно видно светящиеся камни, металл под досками ржавый и
закопчённый.

## Как ложится на модель

Геометрия не меняется, поэтому каждую деталь стандартной модели переосмысляем
текстурой.

| Деталь модели | Было | Станет |
|---|---|---|
| Боковые и задняя панели корпуса | крашеный металл | вертикальные рейки (осина), прибитые гвоздями; щели между рейками → тёмные (normal + AO) |
| Дверца (жёлтая) | крашеный металл | дверца из досок с железными полосами-петлями, следы копоти над окном |
| Смотровое окно | светящееся нутро | **раскалённые камни** (emission): ядро `#FF6A1F`, края `#FFB347`, чёрные трещины между камнями |
| Панель с кнопками | красная кнопка, табло | деревянная плашка; кнопки → деревянные ручки-кругляши; табло → закопчено |
| Манометр | манометр | банный термометр в деревянной оправе (стрелка, без цифр, только шкала-риски) |
| Труба с вентилем (красная ручка) | металл, красная ручка | медная трубка с патиной; ручка → обмотана верёвкой |
| Кабель | чёрный кабель | джутовая верёвка или кабель в тряпичной оплётке |
| Вентиляционная решётка | металл | деревянные рейки-жалюзи |
| Верхняя крышка | металл | по краю — рейки; в центре — закопчённый металл с каплями воды и белым налётом |
| Нижняя рама-подставка | металл | обрезки брёвен/кирпича под рамой (рисуется на раме), ржавчина |
| Мелкие наклейки | предупреждающие наклейки | убрать, вместо них пятна воды, смола, следы от ковша |

> ⚠️ Таблица составлена по иконке предмета. Точное расположение деталей на
> развёртке проверить после скачивания оригиналов.

## Карты

| Карта | Что делаем |
|---|---|
| Diffuse | Дерево, камни, ржавчина, копоть. Без запечённых бликов и теней. |
| Normal | Щели между рейками, волокна дерева, шляпки гвоздей, рельеф камней в окне. |
| Specular / Gloss | Дерево и войлок матовые (низкий gloss); мокрые пятна и медь с патиной чуть глянцевее; камни матовые. |
| Occlusion | Оригинальная + затемнение щелей между рейками. |
| Emission | **Только окно с камнями.** Неравномерно: самые яркие внизу, к верху тускнеют, трещины тёмные. Никакого свечения на корпусе. |
