# Sauna Stove (Electric Furnace)

> Статус: 🟡 v1.3 — полировка (побежалость, базальт, подпалины, жалюзи). Следующий шаг: перезагрузить все 5 карт и проверить со всех сторон днём и ночью.
> Сет: [Sauna](../README.md).

## Образ

Старая эмалированная электроплита, которую выживший превратил в каменку:
обшил корпус рейками, на конфорки навалил камней, и они раскалены снизу.
Сквозь решётку дверцы видно светящиеся камни, металл под досками ржавый и
закопчённый.

## Что за модель (по оригиналам)

Это **старая кухонная электроплита**: эмалированный куб, сверху 4 конфорки
со спиралями, спереди панель с 5 ручками и дверца духовки с решёткой из
вертикальных прутьев, внутри нагревательные спирали, внизу кирпичный цоколь
на деревянном поддоне.

![Виды с оригинальной текстурой](uv/views_tex.png)

## Слоты редактора и оригинальные текстуры

| Слот | Размер | Каналы оригинала | Параметры в редакторе |
|---|---|---|---|
| Diffuse | 2048 | RGB цвет, альфа = 255 (вырезов нет) | Color (тинт RGB), Alpha Cutoff 0.00 |
| Normal | 2048 | R, G — нормаль; B = 255 | Normal Scale 1.00 |
| Metal/Gloss | 2048 | **RGB = металличность** (оттенки серого), **A = глянец** (макс. 215) | Metalness 1.00, Glossiness 0.98 (множители) |
| Occlusion | 512 | оттенки серого | Occlusion Scale 1.00 |
| Emission | 512 | красно-оранжевый, остальное чёрное | Emission Color (тинт RGB) |

Кнопка **Download** вверху панели скачивает 3D-модель (`electric.furnace.obj`
с UV), а стрелки у слотов — PNG-текстуры. Всё лежит в `originals/` (в git, через LFS).

## Версия v1

Сгенерирована скриптом [texture_v1.py](texture_v1.py). Для каждого пикселя
текстуры восстанавливается его 3D-точка на модели, поэтому рейки, камни и
кладка непрерывны через швы развёртки.

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
.venv/Scripts/python skins/sauna/electric-furnace/texture_v1.py
```

### Что смотреть в игре

- Читаются ли рейки издалека или сливаются (тогда расширить доски/углубить щели).
- Не слишком ли яркое/тусклое свечение (крутится ползунок Emission Color или
  множитель в скрипте).
- Нормаль: не «вдавлен» ли рельеф (если да — инвертировать зелёный канал).
- Камни на конфорках: мелкие или крупные.

### Как загрузить в игру

1. Workshop → Create a new item → Electric Furnace → EDIT.
2. **Diffuse** → Import → `export/ElectricFurnace_blocking_v0_diffuse.png`.
3. **Metal/Gloss** → Import → `export/ElectricFurnace_blocking_v0_metalgloss.png`.
4. Normal, Occlusion, Emission не трогать (оригинальные).
5. Покрутить модель, включить ночь (кнопка с луной), сделать скриншоты в
   `screenshots/` — по ним решаем, что править в v1.

### Известные ограничения v0

- Normal оригинальный: на цоколе будут видны швы кирпичей, на боках —
  вмятины эмали. В v1 заменить нормаль на камень и рейки.
- Ручки окрашены как панель (отдельно не выделились).
- Рейки пока не нарисованы — только цвет дерева.

## Как ложится на модель

| Деталь | Было | Станет |
|---|---|---|
| **Верх: 4 конфорки со спиралями** | спирали светятся | **кучи камней**: серый гранит, в щелях между камнями красно-оранжевое свечение (emission по форме бывших спиралей + между камнями) |
| **Дверца-решётка** | ржавые прутья | прутья → кованые чёрные; за ними **раскалённые камни** |
| **Внутренние стенки духовки** (серые острова) | серый металл, спирали | камни и угли, видны сквозь решётку; свечение внизу |
| Ряд из 5 ручек | чёрные ручки на эмали | деревянные ручки-кругляши; одна — банный термометр без цифр |
| Эмалированные бока и перед | кремовая эмаль с ржавчиной | вертикальные рейки (осина), прибитые гвоздями; по краям виднеется ржавая эмаль |
| Задняя панель | серый металл с решёткой и шильдиком | рейки; шильдик убрать (без текста) |
| Цоколь | кирпич | дикий камень на растворе или торцы брёвен, мокрые пятна снизу |
| Поддон | доски | оставить доски, но мокрые и потемневшие |

> 💡 Принят и скин **без свечения** (Cold Hunter), но для каменки свечение
> камней — суть образа, оставляем.

## Карты

| Карта | Что делаем |
|---|---|
| Diffuse | Дерево, камни, ржавчина, копоть. Без запечённых бликов и теней. |
| Normal | Щели между рейками, волокна дерева, шляпки гвоздей, рельеф камней. Делать в том же формате, что оригинал (B = 255). |
| Metal/Gloss | Дерево и камни: металличность 0, глянец низкий. Мокрые пятна — глянец выше. Кованые прутья и проглядывающий металл — металличность высокая. |
| Occlusion | Оригинальная + затемнение щелей между рейками и камнями. |
| Emission | Только щели между камнями сверху и камни/угли внутри духовки. Неравномерно: ярче внизу, к верху тускнеет. На корпусе свечения нет. |
