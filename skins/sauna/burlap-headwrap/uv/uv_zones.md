# UV-зоны модели

Модель: `burlap.headwrap.obj`, треугольников: 1664. Цоколь — всё ниже -10.0 м (тот же цвет, темнее).

| Цвет | Зона | Треугольников |
|---|---|---:|
| rgb(70, 70, 70) | скрыто (внутри духовки, днище, обратные стороны) | 668 |
| rgb(240, 190, 50) | правый бок (+X) | 222 |
| rgb(180, 90, 220) | левый бок (-X) | 219 |
| rgb(60, 200, 120) | зад (-Z) | 215 |
| rgb(60, 150, 235) | перед (+Z) | 201 |
| rgb(230, 60, 60) | верх | 139 |

Файлы: `uv_zones.png` — развёртка по зонам; `uv_wire.png` — прозрачная сетка для слоя; `views.png` — виды по зонам; `views_tex.png` — виды с оригинальной текстурой (проверка).
