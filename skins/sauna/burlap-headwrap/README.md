# Sauna Towel Wrap (Burlap Headwrap)

> Статус: 🟡 блокинг v0 готов — ждёт проверки в игре (19.10.2026).
> Сет: [Sauna](../README.md). Предыдущий предмет: [Sauna Stove](../electric-furnace/README.md).

## Образ

Застиранное льняное банное полотенце, намотанное на голову и шею и перехваченное
льняной бечёвкой: грязно-белый лён `#CFC6B4`, две выцветшие кирпичные полоски `#8E3A30`
вдоль кромки (классическое финское полотенце), бечёвка `#B8A27A`, сырые пятна.
Без текста. Не броня, не бинты: полоски и бечёвка говорят «полотенце».

## Что за модель (по оригиналам)

Не тюрбан, а **капюшон-балаклава** с прорезью для глаз + **шарф-воротник** на шее,
всё из мешковины, капюшон обмотан тремя верёвками (рельеф в Normal и AO).
880 вершин, 1664 треугольника; координаты OBJ: Y вверх, +Z вперёд (лицо).

## Слоты редактора (другой шейдер, чем у печи!)

| Слот | Оригинал | Параметры |
|---|---|---|
| Diffuse | 1024, RGBA: **альфа = рваные края** (низ воротника, края прорези для глаз) | Color, **Alpha Cutoff 0.79** |
| Normal | 1024, OpenGL, B = 255 (переплетение мешковины, складки, верёвки) | Normal Scale 1.00 |
| Specular/Gloss | нет (пустой) | **Spec Color 51/51/51**, Glossiness 0.28 |
| Occlusion | 512 | Occlusion Scale 1.00 |
| Emission | нет | — |
| Fuzz Mask | нет (белый) | **Fuzz 0.23**, Fuzz Scatter 0.53 (+ ниже ещё параметры ворса) |

> Это **specular-схема** (не metal/gloss) и есть **«ворс» (Fuzz)** — бархатистый
> отблеск ткани. Для махры полезно: Fuzz можно поднять.

Файлы в `originals/`: `burlap.headwrap.obj`, `burlapheadwraps_01_{bc,nrm,ao}.png`.

## Блокинг v0

[blocking.py](blocking.py) (`.venv/Scripts/python skins/sauna/burlap-headwrap/blocking.py`):
перекраска оригинала с сохранением складок и переплетения (яркость оригинала, контраст
снижен), полоски вдоль кромки воротника и нижнего края капюшона, верёвки → бечёвка,
сырые пятна. Альфа оригинала без изменений.

![Блокинг v0](uv/blocking_v0_views.png)

### Как загрузить в игру

1. Workshop → Create a new item → **Burlap Headwrap** → EDIT.
2. **Diffuse** → Import → `export/BurlapHeadwrap_blocking_v0_diffuse.png`. **Alpha Cutoff
   оставить 0.79** (рваные края).
3. Normal, Occlusion — оригинальные; Specular/Gloss, Emission — пустые как есть.
4. Попробовать **Fuzz 0.5–0.6** (махровый ворс) и сравнить с 0.23.
5. Скриншоты днём/ночью, спереди/сбоку/сзади → `screenshots/blocking_v0_*` (прислать в чат).

### Что смотреть

- Читается ли как **полотенце**, а не как бинты/мумия (если бинты — полоски шире и ярче,
  махра заметнее).
- Не слишком ли светлое/чистое для Rust (Facepunch: «items should look dirty and worn»).
- Видна ли бечёвка; не спорит ли с полосками.
- Нормаль оригинала — грубое переплетение мешковины; для махры в v1 заменить на петли
  махры + складки.

## Дальше (v1)

- Нормаль: махровые петли (мелкий шум) вместо мешковины, складки оставить, бечёвку — витую.
- Specular/Gloss: сухое полотенце матовое, сырые пятна — блестят сильнее.
- Fuzz Mask: ворс на махре, без ворса на бечёвке и мокрых пятнах.
- Износ: застиранные пятна, выдернутые нитки, торчащие петли по кромке; копоть/смола от бани?
- Вариант «войлочная банная шапка» — только если полотенце не зайдёт (геометрия балаклавы
  ему подходит хуже).
