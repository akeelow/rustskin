# Sauna Towel Wrap (Burlap Headwrap)

> Статус: ⚪ старт 19.10.2026 — ждём оригиналы из редактора (`originals/`).
> Сет: [Sauna](../README.md). Предыдущий предмет: [Sauna Stove](../electric-furnace/README.md).

## Образ

Застиранное льняное полотенце, накрученное на голову тюрбаном: грязно-белый лён
`#CFC6B4` с выцветшей кирпичной полосой `#8E3A30`, махровая фактура, мокрые пятна,
торчащие нитки. Альтернатива — войлочная банная шапка (`#B3A48A`) — выбрать после
разбора модели.

## Что скачать из редактора

Workshop → Create a new item → **Burlap Headwrap** → **EDIT**:

1. **Download** (вверху панели MATERIALS) → `burlap.headwrap.obj` (или как назовёт игра).
2. Жёлтая стрелка у **каждого** слота с текстурой (Diffuse, Normal, Metal/Gloss,
   Occlusion, Emission — какие есть).
3. Если у предмета несколько материалов (переключатель/список вверху) — модель и
   текстуры каждого.
4. Скриншот панели EDIT (слоты, размеры, значения ползунков) и 2–3 скриншота
   оригинала на персонаже (спереди, сбоку, сзади).

Всё в `originals/` (скриншоты — в `screenshots/orig_*.webp`).
