## 2. Ограничения (важно)

- Скин = **только текстуры**. Геометрия и развёртка модели фиксированы. Нельзя ничего добавить
  или убрать в форме — только нарисовать/запечь и спрятать альфой (Alpha Cutoff).
- Игру запускает **пользователь**; ты готовишь файлы и просишь скриншоты. Ты не видишь игру.
- Правила сета (из `../README.md`): материалы — светлая осина/липа, потемневшее от пара дерево,
  лён, войлок; самодельность (гвозди, кривые стыки, верёвка); износ (вода, минералы, копоть);
  свечение только «естественное»; **без текста и логотипов**; не броня.
- Палитра — таблица в `../README.md` (осина `#C2A77E`, потемневшее `#7A5A3C`, лён `#CFC6B4`,
  кирпичная полоса `#8E3A30` и т. д.).

## 3. Процесс (обязателен — так решил пользователь)

**Всё делается через Blender:** детали (рейки, фаски, гвозди, подголовник, полотенце) моделируются
high-poly поверх оригинальной модели и **запекаются** на её развёртку (цвет, Normal, AO,
кривизна/ID, маска альфы), потом доводятся скриптом (износ, палитра). Чисто нарисованные маски —
только для мелких правок цвета. Образцы: `../electric-furnace/bake_v2.py`,
`../hide-poncho/towel_neck_bake.py` + `compose_neck.py`.

Инструменты:
- Blender 5.2.2: `C:/Program Files (x86)/Steam/steamapps/common/Blender/blender.exe`, скрипты
  `blender -b -P <script> -- <args>`. GPU OptiX (RTX 3060 Ti), запекание 2048 ≈ 1 мин.
- Blender MCP (живое окно пользователя): если инструменты `mcp__blender__*` доступны — смотри
  результат через `look`. Пользователь должен держать MCP-сервер включённым (N → MCP for Blender).
- Python `.venv` (numpy, Pillow) для сборки текстур. **В Python Blender'а нет PIL** — сохраняй
  PNG через `bpy.data.images` или собирай в `.venv`.
- **Проверка до игры обязательна:** `tools/blender/viewer.py` → лист 12 видов (день/ночь) + `.blend`;
  посмотри лист сам, потом отправь пользователю и можешь открыть ему окно Blender со сценой.

## 5. Грабли, на которые уже наступали (учти заранее)

- **Ползунки редактора по умолчанию** бывают не нейтральными: Diffuse **Color 178** (всё темнее на
  30 %), **Emission Color 0/0/0** (свечение не видно), Alpha Cutoff, Spec Color 60. Всегда пиши
  пользователю, какие значения выставить.
- **Общие участки развёртки:** одинаковые части (ниши, полки, двери, обе стороны двусторонних
  пластин) часто используют одну область текстуры — нарисованное повторится везде. Проверяй это
  до проектирования (raster по объектам/граням).
- **Двусторонние пластины** (дверцы, шкуры, ткань): внутренняя и внешняя стороны могут делить
  UV — растеризуй наружные грани последними.
- **Запекание selected-to-active** ловит не те слои (второй лист, стенки дыр, складки): ограничивай
  `max_ray_distance`, держи только передний слой (z-буфер), чисти маску (closing/opening, мелкие
  куски), проверяй тёмные/серые пятна на листе.
- **Альфа-вырезы:** край режется по пикселям — запекай 2048 и делай мягкую маску; цвет за краем
  продлевай (иначе серая кайма). Facepunch иногда не принимает прозрачность, через которую что-то
  видно — согласуй с пользователем.
- **Свечение днём** тоже прибавляет яркость; в игре сильный bloom — свечение делай слабее, чем
  кажется в Blender.
- **Не меняй то, что пользователь похвалил** при исправлении другого места (пончо v5.1 испортило
  удачную спину).
- Если форма модели не позволяет задуманное — **скажи прямо и предложи варианты**, не крути
  десятки итераций.
