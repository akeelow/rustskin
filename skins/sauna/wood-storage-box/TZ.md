## 1. Контекст

Сет **Sauna** — «сауна из мусора, собранная выжившим», скины Rust для Steam Workshop. Готовы и проверены
в игре: каменка, полотенце-тюрбан, вафельный халат, шкафчик, полок (кровать), кресло. Публикация одной
коллекцией **до конца ноября 2026** — на этот предмет есть **3–5 рабочих дней**.
Параллельно может работать агент Workshop-пакета (`../TZ_workshop_pack.md`) — его файлы не трогай.

**Твоя задача:** предмет №8 — **Wood Storage Box → «Sauna Tub»** (рабочее имя; финальное — по концепту).

Что известно о предмете (`data/item-ranking.csv`, 18.10.2026): за год подано 386, принято 21 (**1 из 18** —
самый низкий шанс в сете), медиана продаж ~13 000, цена $1.99, **у 71 % принятых есть свечение**.
Ящики ставят рядами в базе и смотрят на них **сверху и спереди** (открывая) — крышка и перед важнее всего.

## 2. Главное ограничение и образ

Скин = **только текстуры**; геометрия и развёртка фиксированы. Модель — **прямоугольный ящик**, поэтому
**круглую кадушку из сета нарисовать нельзя** (это было бы видно сразу). Образ строим на форме ящика.
Разбери модель и предложи пользователю **2–3 концепта** на неё, например:

- **A. «Sauna Tub» — прямоугольный ушат.** Ящик собран из клёпок-досок, как кадка, стянут **стальными
  обручами** по периметру (ржавые, с заклёпками), на крышке — деревянный **ковш** (нормалью/цветом,
  если есть подходящий объём — high-poly и запекание) и сложенное полотенце. Дерево мокрое, низ
  потемнел, белые минеральные разводы, по шву капли. Ближе всего к заявленному имени.
- **B. «Sauna Chest» — короб для веников и полотенец.** Сундук из вагонки (как спинка кресла),
  к крышке бечёвкой привязаны **сушёные берёзовые/дубовые веники**, сверху стопка льняных полотенец
  с кирпичной полосой; сухо, светлее остальных предметов, листья на полу/крышке.
- **C. «Sauna Woodbox» — ящик у каменки.** Короб для дров/камней, закопчённый с одного бока (тот, что к
  каменке), обожжённые края, кучка базальта/поленьев (только если у модели есть открытый верх).

**Свечение** (71 % принятых — со свечением) — **предложи, но не навязывай** и согласуй с пользователем:
например, тлеющие угли/камни в ковше или в щели (концепт C), фонарь-свеча на крышке. Правило сета —
свечение только там, где оно оправдано историей, и слабее, чем кажется в Blender (в игре сильный bloom;
у шкафчика по умолчанию **Emission Color 0/0/0** — без 255 ничего не светится).

Сквозные мотивы сета (бери цвета из готовых предметов, а не придумывай заново): осиновые рейки и ржавая
сталь — `../bed/`, вагонка, листья веника (бурый дуб, зелёная/сухая берёза **с прожилками**) —
`../chair/`, льняное полотенце с кирпичной полосой — `../burlap-headwrap/`, `../locker/`.

## 3. Ограничения

- Игру запускает **пользователь**; ты готовишь файлы и просишь скриншоты.
- Правила сета: осина/липа, потемневшее от пара дерево, лён, войлок; самодельность; износ (у каждого
  пятна — причина); **без текста, цифр и логотипов**; не броня. Палитра — в `../README.md`.
- Альфа-вырезы на ящике **не делать** без явного согласия пользователя: коллизия остаётся, а сквозная
  прозрачность — риск отказа Facepunch.

## 4. Процесс (обязателен)

**Всё через Blender с запеканием** (решение пользователя): детали (доски, фаски, щели, обручи, заклёпки,
гвозди, ковш, полотенце, веники) моделируются high-poly поверх оригинала и запекаются на его развёртку
(цвет/ID, Normal, AO, кривизна), потом доводятся в `.venv` (износ, палитра). **Перед каждой отдачей в
игру** — лист `tools/blender/viewer.py` (12 видов, день/ночь): посмотри сам, отправь пользователю, можно
открыть ему окно Blender со сценой.

1. Попроси пользователя: Workshop → Create a new item → **Wood Storage Box** → EDIT → **Download** (OBJ),
   жёлтые стрелки у всех слотов, список материалов, **скриншот панели EDIT целиком** (все ползунки и их
   значения по умолчанию), 3 кадра модели (перед, 3/4 сверху, сзади). Файлы → `originals/`.
2. Разбор: **оси и единицы OBJ** (Bed был Z-up/см из 3ds Max, Chair — Y-up/м), UV вне 0…1 (тайлы),
   **общие участки развёртки** (у ящика стороны/доски/уголки вполне могут делить одни текселя — тогда
   рисунок повторится; проверь до концептов), открывается ли крышка и видно ли внутренность, есть ли у
   модели свои доски/уголки/ручки, на которые лягут обручи. Удобно — острова, как `../chair/islands.py`.
3. Бриф `README.md` (по образцу `../chair/README.md`): модель, слоты и **ползунки по умолчанию**, развёртка,
   концепты (2–3 картинки поверх реальной модели) → выбор пользователя.
4. Блокинг v0 цветом → в игру. Потом v1+: `bake_tub.py` (Blender) + `texture_v1.py` (.venv) → лист →
   в игру → итерации по скриншотам до «готово».
5. Workshop-пакет как у кресла: `workshop/README.md` (таблица загрузки, название **без скобок и без
   оригинального имени** — только `Sauna …`, описание на английском: история, последняя строка
   «Part of the Sauna set.») + `workshop_renders.py` (кадр рядом с полоком/каменкой — предметы из одного дома).

## 5. Грабли

Раздел 5 в `../bed/TZ.md` и «Заметки» в `../chair/README.md`. Самое частое:
- **ползунки по умолчанию** не нейтральны (Color 178, Emission Color 0, Alpha Cutoff, Spec Color 60) —
  всегда пиши пользователю точные значения;
- **«пластик»**: кресло v1 читалось садовым пластиковым креслом — дереву нужны стыки досок, гвозди,
  торцы, неровный тон по доске, матовость (gloss ниже, чем хочется);
- **жёлтые кляксы на солнце**: светлые листья/пятна днём выгорают — проверяй лист днём, листья темнее и
  с прожилками (кресло v1.4);
- обводки вместо пятен (мокрый круг кресла v1 читался контуром) — пятна мягкие, с причиной;
- запекание ловит не тот слой — `max_ray_distance`, передний слой, чистка маски;
- **не портить похваленное**; если форма модели не позволяет задуманное — скажи прямо и предложи варианты;
- в Python Blender'а **нет PIL** — PNG через `bpy.data.images` или сборка в `.venv`.
