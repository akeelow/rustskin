# UV-зоны модели

Модель: `locker.obj`, треугольников: 1499. Цоколь — всё ниже -10.0 м (тот же цвет, темнее).

| Цвет | Зона | Треугольников |
|---|---|---:|
| rgb(70, 70, 70) | скрыто (внутри духовки, днище, обратные стороны) | 908 |
| rgb(60, 150, 235) | перед (+Z) | 284 |
| rgb(230, 60, 60) | верх | 93 |
| rgb(60, 200, 120) | зад (-Z) | 76 |
| rgb(240, 190, 50) | правый бок (+X) | 74 |
| rgb(180, 90, 220) | левый бок (-X) | 64 |

Файлы: `uv_zones.png` — развёртка по зонам; `uv_wire.png` — прозрачная сетка для слоя; `views.png` — виды по зонам; `views_tex.png` — виды с оригинальной текстурой (проверка).
