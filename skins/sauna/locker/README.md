# Sauna Changing Locker (Locker)

> Статус: ⚪ старт 19.10.2026 — ждём оригиналы из редактора (`originals/`).
> Сет: [Sauna](../README.md).

## Образ

Шкафчик раздевалки бани: дверцы из светлых осиновых реек (как обшивка каменки),
вентиляционные щели, деревянные крючки, ручки-плашки, номерок — без цифр (правило сета:
без текста), на дверце висит застиранное полотенце с кирпичной полоской (нарисованное),
потемневшее от пара дерево внизу, ржавые петли.

## Что скачать из редактора

Workshop → Create a new item → **Locker** → **EDIT**:

1. **Download** (вверху панели MATERIALS) → `.obj` модели.
2. Жёлтая стрелка у **каждого** слота с текстурой (Diffuse, Normal, Metal/Gloss или
   Specular/Gloss, Occlusion, Emission — какие есть).
3. **Материалов может быть несколько** (подпись под MATERIALS) — у шкафчика часто
   отдельные материалы корпуса, дверец или содержимого; скачать модель и текстуры каждого.
4. Скриншот панели EDIT целиком (пролистать до конца) и 3–4 кадра шкафчика: спереди,
   сбоку, сзади, **с открытыми дверцами** (если в редакторе можно), чтобы видеть, что внутри.

Файлы — в `originals/`, скриншоты — в чат.
