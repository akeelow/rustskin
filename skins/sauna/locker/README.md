# Sauna Changing Locker (Locker)

> Статус: 🟡 **v4 — по макету дизайнера** (столярка, встроенный свет, липа), ждёт проверки в игре. v1 (закрытый) готов; v2, v3 проверены.
> Сет: [Sauna](../README.md).

## Образ

Шкафчик раздевалки бани: дверцы из светлых осиновых реек (как обшивка каменки),
вентиляционные щели, деревянные крючки, ручки-плашки, номерок — без цифр (правило сета:
без текста), на дверце висит застиранное полотенце с кирпичной полоской (нарисованное),
потемневшее от пара дерево внизу, ржавые петли.

## Что за модель (по оригиналам)

Три стальных шкафчика в ряд: левый и правый — металлические дверцы с жалюзи
(вентиляция) и ручкой-защёлкой/рычагом, средний — самодельная **деревянная** дверца из
досок с поперечинами и ящиком внизу; рама с заклёпками, ножки. Дверцы — отдельные
объекты (`locker_door_a/b/c`). 790 вершин, единицы — **сантиметры**: x −90…90,
y 0…224 вверх, +z — перед. Один материал `MAIN`.

## Версия v4: по макету дизайнера

Макет: [references/sauna/locker/designer_detailed_skin.html](../../../references/sauna/locker/designer_detailed_skin.html)

[texture_v4.py](texture_v4.py) (`.venv/Scripts/python skins/sauna/locker/texture_v4.py`).
Корпус — три блока по 60 см (центры −60, 0, 60), детали рисуются в локальных координатах блока.

| Деталь (номера макета) | Как сделано |
|---|---|
| 1 Карниз | верх — доски термолипы `#6A4426` вдоль, светлее к передней кромке |
| 2 Фриз | паз по длине + ряд из 7 отверстий над нишей (Normal + тень, свечение 30 %) |
| 3 LED-щель | передняя полоса потолка ниши (свечение 90 %) |
| 4 Стойки | старая липа `#A8743E`, фаски, светлая затёртость на уровне рук |
| 5 Нагели | пары шкантов на стыках стоек с полками и фризом |
| 6 Вагонка спинки | доски 9 см `#9A6534`, паз с тенью, разный тон, сучки |
| 7 Светильник | плафон с деревянной решёткой на спинке верхней ниши (свечение 75 %) + ореол на дереве |
| 8 Вешалка-планка | планка на шурупах, три крючка-колышка с тенью |
| 9 Прорези | три вертикальные в середине спинки (свечение 20 %) |
| 10 Полки | рейки светлой липы `#D8AA70` с зазорами, затёртая передняя кромка, LED по кромке, опорные бруски на боковинах |
| 11 Ящик | рамка + скошенная филёнка (ручка — стальная геометрия) |
| 12 Цоколь | термолипа с прорезями (свечение 30 %), стальные ножки, потемнение от воды |
| Спинка снаружи | рамка + филёнки из вагонки на каждый блок, сетка отверстий сверху, прорези снизу, нагели |
| Износ | вода снизу, затёртые кромки, разный тон досок, тень в углах ниш |

**Ночь:** свет на дереве — в Emission (Diffuse ночью чёрный): под каждой LED-полосой отсвет на
спинке и перегородках (до 60 % тона дерева), ореол светильника, полки и пол слабее. LED — тёплый
белый, не оранжевый.

**Поправки к макету (модель):** три ниши одинаковые (общая развёртка); LED — по кромке полки (верх
и низ полки — одна развёртка); прорезей в нижней нише нет (там полоска развёртки); **боковины
снаружи** делят развёртку с внутренней стороной крайних стенок ниш — на них вагонка с брусками
(снаружи читается как доски с поперечинами), без рамки с филёнками и без свечения.

## Версия v3: открытый шкафчик, полный банных вещей

По v2 в игре (`screenshots/v2_*`): прозрачные дверцы работают (дыр нет), но скучно, а подсветки
не было, потому что у шкафчика **Emission Color по умолчанию 0/0/0** — его надо выставить на
255/255/255. Конкурент (`references/sauna/locker/competitor_pirate_locker_*`) берёт деталями:
каждая зона текстуры чем-то занята.

1. [props_v3.py](props_v3.py) — Blender: в одном отсеке смоделированы предметы и отрендерены
   ортокамерой прямо на заднюю стенку → `bake/props_{albedo,normal,shade,emit}.png`.
2. [texture_v3.py](texture_v3.py) — каждый тексель задней стенки (она **одна на все три отсека**)
   берёт из рендера цвет, мягкую тень и нормаль (перевод в касательное пространство стенки);
   дверцы и подсветка полок — как в v2; фонарь светится.

```bash
"C:/Program Files (x86)/Steam/steamapps/common/Blender/blender.exe" -b -P skins/sauna/locker/props_v3.py
.venv/Scripts/python skins/sauna/locker/texture_v3.py
```

| Секция | Предметы |
|---|---|
| верх (165–217 см) | деревянная шайка с двумя обручами и ковшом, **фонарь со свечой** (светится), войлочная банная шапка на колышке |
| середина (84–163) | застиранное полотенце с кирпичными полосками на колышке, берёзовый веник |
| низ (49–81) | поленница берёзовых поленьев (торцами наружу), две бутылочки масла из янтарного стекла, мыло |

Все три отсека одинаковые (общая развёртка). Предметы нарисованы на задней стенке: сбоку под
острым углом они плоские.

## Версия v2 (эксперимент): открытый шкафчик с тёплой подсветкой

[texture_v2.py](texture_v2.py) (`.venv/Scripts/python skins/sauna/locker/texture_v2.py`), поверх v1.

| Что | Как |
|---|---|
| Дверцы | альфа 0 у всех трёх дверец (отдельные объекты; двусторонние с общей развёрткой — уходят обе стороны; тексели, общие с корпусом, оставлены) → **Alpha Cutoff 0.5** |
| Внутри | на задней стенке каждого отсека: полотенце с кирпичной полоской на колышке (средняя секция), **берёзовый веник** на колышке (верхняя) |
| Свечение | тёплая янтарная полоса по передней кромке полок + мягкий свет от неё на задней и боковых стенках ниже; больше ничего не светится |

Ограничения развёртки: три отсека **используют один и тот же участок текстуры** (как и полки —
верхняя и средняя), поэтому все отсеки одинаковые, и светятся обе полки.
