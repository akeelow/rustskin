## Образ

Дверь парилки, собранная из мусора: на старое ржавое железо гвоздями набита **вертикальная вагонка**.

| Деталь | Что |
|---|---|
| Вагонка | светлая осина `#C2A77E` (серее, не жёлто-оранжевая — ошибка шкафчика из [CRITIQUE_ART.md](../CRITIQUE_ART.md)); у низа и вокруг ручки потемнела от пара до `#7A5A3C`; доски разной ширины и тона, фаски, щели |
| Железо | ржавый лист `#8C4A26` виден в щелях между досками и по кромке двери |
| Окошко | небольшое, в самодельной рамке, стекло запотело; за ним тёплый свет каменки `#FF6A1F` → `#FFB347` (эмиссия, мягкая, с рисунком: ярче внизу, где камни) |
| Ручка | деревянная скоба, затёртая и потемневшая в месте хвата |
| Полотенце | на кованом крючке, застиранное `#CFC6B4`, с кирпичной полосой `#8E3A30` — сквозной мотив сета |
| Банный лист | один берёзовый лист, прилипший к мокрому низу — второй мотив сета |
| Крепёж | самодельные кованые петли, проволочная скрутка, шляпки гвоздей с ржавым ореолом |
| Износ | подтёки воды, белые минеральные разводы, смола в сучках |
| Под замок | спокойное поле без деталей там, где игра ставит кодовый и навесной замок (место уточняется по модели и кадру из игры) |

**Две стороны.** «В предбанник» — светлая сухая осина, полотенце, окошко светится. «В парилку» —
дерево темнее (`#7A5A3C` → `#45332A` кверху), копоть вверху, больше воды и разводов, полотенца нет.
Если у модели обе стороны делят один участок развёртки, различить их нельзя — тогда скажу об этом
прямо и сделаю одну сторону, пригодную для обеих.

**Тир.** Железо только как старая основа в щелях и по кромке; снаружи дверь — дощатая, без брони,
накладок и заклёпок поверх дерева.

## План работы

1. Разбор модели: оси и единицы OBJ, острова развёртки по сторонам, перекрытия и зеркала, размер
   текселя → `uv/` (`tools/uv_zones.py`).
2. `bake_door.py` (Blender, headless): high-poly доски с фасками и щелями, окно с рамкой и стеклом,
   ручка-скоба, петли, крючок, полотенце со складками, гвозди, проволока, лист → запекание
   Normal, AO, ID, кривизны, эмиссии окна в `bake/`.
3. `texture_v1.py` (`.venv`): раскраска по ID и палитре сета, износ, сборка карт под слоты → `export/Door_v1_*`.
4. `tools/blender/viewer.py`: лист день/ночь и сцена `.blend` → `renders/`.
5. Самопроверки (швы, отступы островов, иконки 128/64 и ч/б, сверка со шкафчиком и каменкой в одном
   свете, правила сета, лимиты редактора) — результаты с картинками сюда.
6. `workshop/README.md`: название `Sauna Door`, описание на английском, порядок картинок.

## Нужно от пользователя

В Rust: **Workshop → Create a new item → Wooden Door → EDIT**.

1. **Download** вверху панели MATERIALS → `originals/door.obj` (имя как сохранит игра — не важно).
2. **Жёлтая стрелка у каждого слота** каждого материала → PNG в `originals/`: Diffuse, Normal,
   Specular/Gloss (или Metal/Gloss), Occlusion, Emission — какие есть. Если материалов несколько —
   все, и список их названий.
3. **Скриншот панели EDIT целиком** для каждого материала: значения Color, Alpha Cutoff, Normal Scale,
   Spec Color / Metalness, Glossiness, Occlusion Scale, Emission Color и подписи «Default (W x H)»
   под слотами.
4. **Три кадра стандартной двери** в редакторе → `screenshots/`: спереди, сзади, три четверти.
5. Если несложно, кадр из игры: Wooden Door с **кодовым замком** и с **навесным** (обе стороны) —
   по нему оставлю под замок спокойное место. Без кадра оценю место по модели и помечу как
   непроверенное.
