# Sauna Towel Poncho (Hide Poncho)

> Статус: 🟡 **v2 — только полотенце, остальное прозрачное**: два варианта (на шее / на плече), ждут проверки в игре. v1 (полотенце-пончо целиком) — запасной.
> Сет: [Sauna](../README.md). Халат ушёл на Snow Jacket, поэтому образ пончо пересматриваем.

## Варианты образа

| # | Образ | Почему | Риск |
|---|---|---|---|
| A | **Овчинная накидка** — шкура мехом внутрь, кожа наружу, мех по краю, ремешок на палочке-застёжке | Hide Poncho и так из шкуры; палитра сета (`#8A6646` / `#D6C8AC`); наработки отложенного тулупа (`../snow-jacket/texture_v1.py`) — кожа, мех, маска ворса; «выскочить из бани в снег» | ближе к обычному пончо, меньше «банного» юмора |
| B | **Войлочная банная накидка** — серо-бежевый войлок `#B3A48A`, простой вышитый узор по краю (орнамент без текста), кисти | рифмуется с войлочной шапкой из шкафчика; мягко, тепло, узнаваемо | войлок плоский — нужен хороший ворс/нормаль |
| C | **Махровое полотенце-пончо** — большое полотенце с дыркой для головы, широкие выцветшие полосы, бахрома | смешно за счёт ситуации (правило сета 6), читается издалека | повторяет полотенце-тюрбан и халат по материалу |

## Что за модель (по оригиналам)

Шкура, накинутая на плечи: два слоя (наружный и передняя накидка-клапан), спереди застёжка на
деревянных палочках, на правом плече — клок меха (отдельный меш `fur` из полосок-карточек с
альфой). Один материал MAIN. Модели: `attire.hide.poncho_poncho.obj` (1707 вершин),
`attire.hide.poncho_fur.obj`. Метры, Y вверх, +Z вперёд.

| Слот | Оригинал | Параметры |
|---|---|---|
| Diffuse | 1024, RGBA: альфа — только у полосок меха (правый нижний угол) | **Color 178/178/178** (приглушает!), **Alpha Cutoff 0.24** |
| Normal | 512 | Normal Scale 1.00 |
| Specular/Gloss | нет | Spec Color 60/60/60, Glossiness 0.48 |
| Occlusion | 256 | 1.00 |
| Emission | нет | — |

Скриншоты: [screenshots/orig_editor_front.webp](screenshots/orig_editor_front.webp), [orig_side](screenshots/orig_side.webp), [orig_back](screenshots/orig_back.webp).
Развёртка: [uv/poncho/uv_zones.png](uv/poncho/uv_zones.png), [uv/fur/uv_zones.png](uv/fur/uv_zones.png).

## Версия v2: свёрнутое полотенце, остальная шкура прозрачная

По просьбе пользователя (референсы `references/sauna/poncho/towel_round_neck.png`,
`towel_over_shoulder.png`): полотенце, сложенное вдоль, на шее концами вперёд — или на плече.
Геометрия шкуры та же, поэтому полотенце — это полоса шкуры с альфой 255, всё остальное (спина,
клапан, мех, прищепки) — альфа 0 (**Alpha Cutoff 0.24**).

[texture_v2.py](texture_v2.py) (`.venv/Scripts/python skins/sauna/hide-poncho/texture_v2.py`).

| Вариант | Форма |
|---|---|
| `neck` | полоса 7 см вокруг ворота + два конца по груди по бокам от шеи (до ~1.08 м), на концах — полосы и бахрома |
| `shoulder` | полоса 20 см через левое плечо, свисает на грудь и на спину, полосы и бахрома на обоих концах |

Полоса «скруглена» в нормали (сложенное полотенце толще посередине), тёмные линии сгиба по краям,
махра. Сзади у `neck` сквозь пустую спину видна изнанка передних концов — это нормально.

![v2](uv/v2_preview.png)

### Как загрузить в игру

| Слот | Файл / значение |
|---|---|
| Diffuse | `export/HidePoncho_v2_neck_diffuse.png` или `..._shoulder_diffuse.png`, **Color 255/255/255**, **Alpha Cutoff 0.24** |
| Normal | `export/HidePoncho_v2_neck_normal.png` или `..._shoulder_normal.png` |
| Occlusion | убрать (крестик) или оставить — AO шкуры может затемнять полотенце пятнами |

## Заметки

- 19.10.2026, варианты в игре (`screenshots/{A,B,C}_*`): A (овчина) — совсем не банный; B (войлок) —
  непонятно что; **C — похоже на полотенце** → выбран. Минусы C: полосы шли по всем краям (V клапана,
  ворот, кольца вокруг дыр сзади) — как принт, а выцветший кирпичный стал розовым («бекон»).

![сзади](uv/variants_back.png)

| | Diffuse | Normal | Мех на плече |
|---|---|---|---|

## Что скачать из редактора

Workshop → Create a new item → **Hide Poncho** → **EDIT**:

1. **Download** → `.obj`.
2. Жёлтая стрелка у каждого слота с текстурой.
3. Несколько материалов? — скачать каждый.
4. Скриншот панели EDIT целиком (пролистать до Fuzz) + 3 кадра на персонаже: спереди, сбоку, сзади.
