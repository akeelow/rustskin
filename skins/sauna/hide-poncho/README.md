# Hide Poncho — банный сет (образ выбирается)

> Статус: ⚪ старт 19.10.2026 — ждём оригиналы из редактора (`originals/`) и выбор образа.
> Сет: [Sauna](../README.md). Халат ушёл на Snow Jacket, поэтому образ пончо пересматриваем.

## Варианты образа

| # | Образ | Почему | Риск |
|---|---|---|---|
| A | **Овчинная накидка** — шкура мехом внутрь, кожа наружу, мех по краю, ремешок на палочке-застёжке | Hide Poncho и так из шкуры; палитра сета (`#8A6646` / `#D6C8AC`); наработки отложенного тулупа (`../snow-jacket/texture_v1.py`) — кожа, мех, маска ворса; «выскочить из бани в снег» | ближе к обычному пончо, меньше «банного» юмора |
| B | **Войлочная банная накидка** — серо-бежевый войлок `#B3A48A`, простой вышитый узор по краю (орнамент без текста), кисти | рифмуется с войлочной шапкой из шкафчика; мягко, тепло, узнаваемо | войлок плоский — нужен хороший ворс/нормаль |
| C | **Махровое полотенце-пончо** — большое полотенце с дыркой для головы, широкие выцветшие полосы, бахрома | смешно за счёт ситуации (правило сета 6), читается издалека | повторяет полотенце-тюрбан и халат по материалу |

## Что скачать из редактора

Workshop → Create a new item → **Hide Poncho** → **EDIT**:

1. **Download** → `.obj`.
2. Жёлтая стрелка у каждого слота с текстурой.
3. Несколько материалов? — скачать каждый.
4. Скриншот панели EDIT целиком (пролистать до Fuzz) + 3 кадра на персонаже: спереди, сбоку, сзади.

Файлы — в `originals/`, скриншоты — в чат.
