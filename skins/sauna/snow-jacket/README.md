# Sauna Sheepskin (Snow Jacket)

> Статус: ⚪ старт 19.10.2026 — ждём оригиналы из редактора (`originals/`).
> Сет: [Sauna](../README.md). ⚠️ Snow Jacket принимают только **декабрь–февраль** —
> опубликовать до конца ноября 2026.

## Образ

Овчинный тулуп «выскочить из парной в снег»: рыже-коричневая кожа `#8A6646` наружу,
молочный мех `#D6C8AC` на воротнике, манжетах и по краям, потёртости на локтях и
швах, застёжка — деревянные палочки на кожаных петлях или бечёвка (правило сета:
верёвка вместо креплений). Иней/снег на плечах — по желанию. Без текста.

## Что скачать из редактора

Workshop → Create a new item → **Snow Jacket** → **EDIT**:

1. **Download** (вверху панели MATERIALS) → `.obj` модели.
2. Жёлтая стрелка у **каждого** слота с текстурой (Diffuse, Normal, Specular/Gloss или
   Metal/Gloss, Occlusion, Emission, Fuzz Mask — какие есть).
3. **Материалов у куртки может быть несколько** (подпись под MATERIALS: MAIN, …) —
   переключить и скачать модель и текстуры каждого.
4. Скриншот панели EDIT целиком (видны слоты, размеры, ползунки — пролистать вниз до
   Fuzz) и 3 кадра оригинала на персонаже: спереди, сбоку, сзади.

Файлы — в `originals/`, скриншоты — в чат (сохраню как `screenshots/orig_*`).
