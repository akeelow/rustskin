## 1. Контекст

Сет **Sauna** — «сауна из мусора, собранная выжившим», скины Rust для Steam Workshop. Готовы: каменка,
полотенце-тюрбан, вафельный халат, шкафчик, полок (кровать). Публикация коллекцией до конца ноября 2026.
Параллельно другой агент делает Workshop-пакет (`../TZ_workshop_pack.md`) — его папки не трогай.

**Твоя задача:** предмет №7 — **Chair → «Sauna Stool»**, банная табуретка / лавка.

## 2. Образ (предложение — согласуй с пользователем после разбора модели)

Табуретка, собранная выжившим из того же, что и полок: **осиновые рейки от поддона** на сиденье;
ножки и царги — из того, что есть у модели (металлический каркас — ржавая сталь, как швеллер у полока).
Сиденье **отполировано**, низ ножек **потемнел от воды**, на сиденье **след от шайки** (мокрый круг) и
прилипший **берёзовый лист**. Акцент — **сложенное полотенце** с кирпичной полоской на краю сиденья или
через спинку, если она есть (сквозной мотив сета; цвета и полосы — из `../bed/` и `../burlap-headwrap/`).
Спинка (если есть) — рейки или доска от двери с облезлой краской, как изголовье полока: предметы
«из одного дома». Предложи пользователю 2–3 концепта по реальной модели (как у полока: «голый»,
«с тканью», «запасной без альфы»).

## 3. Ограничения

- Скин = **только текстуры**; геометрия и развёртка фиксированы. Убрать часть можно только альфой.
- Игру запускает **пользователь**; ты готовишь файлы и просишь скриншоты.
- Правила сета: осина/липа, потемневшее от пара дерево, лён, войлок; самодельность; износ; свечения у
  табуретки нет; **без текста и логотипов**; не броня. Палитра — в `../README.md`.

## 4. Процесс (обязателен)

**Всё через Blender с запеканием** (решение пользователя): детали моделируются high-poly поверх оригинала
и запекаются на его развёртку (цвет, Normal, AO, кривизна/ID, маска альфы), потом доводятся в `.venv`
(износ, палитра). **Перед каждой отдачей в игру** — лист `tools/blender/viewer.py` (12 видов, день/ночь):
посмотри сам, отправь пользователю, можно открыть ему окно Blender со сценой.

1. Попроси пользователя: Workshop → Create a new item → **Chair** → EDIT → **Download** (OBJ), жёлтые
   стрелки у всех слотов, список материалов, скриншот панели EDIT целиком (все ползунки), 3 кадра.
   Файлы → `originals/`.
2. Разбор: **проверь оси и единицы OBJ** (у Bed был экспорт 3ds Max: Z вверх, сантиметры, а
   `tools/uv_zones.py` ждёт Y вверх и метры; пример приведённой копии — `../bed/source/bed_yup_m.obj`,
   разбор — `../bed/uv/CHECK.md`); UV за пределами 0…1 (тайлы); общие участки развёртки
   (`uv_overlap.png`); скрытые грани; двусторонние детали.
3. Бриф `README.md` (по образцу `../bed/README.md`): модель, слоты и **значения ползунков по умолчанию**,
   развёртка, концепты → выбор пользователя.
4. Блокинг v0 → в игру. Потом v1+: `bake_stool.py` (Blender) + `texture_v1.py` (.venv) → лист → в игру →
   итерации по скриншотам до «готово».
5. Workshop-пакет как у полока: `workshop/README.md` (таблица загрузки, описание на английском,
   картинки) + `workshop_renders.py`.

## 5. Грабли

Прочитай **раздел 5 в `../bed/TZ.md`** и заметки в `../bed/README.md` — там всё, на что уже наступали:
ползунки по умолчанию (Color 178, Emission Color 0, Alpha Cutoff); общие участки UV; двусторонние
пластины; запекание ловит не тот слой; серая кайма на краю альфы; не портить похваленное; если форма
модели не позволяет — сказать прямо. Ещё: **в Python Blender'а нет PIL** — PNG сохраняй через
`bpy.data.images` или собирай в `.venv`.
